# Product Definition - RAG Pro Max

## Overview
RAG Pro Max is an enterprise-grade intelligent document Q&A and data analysis system. It integrates full-scale document retrieval (RAG), automated web scraping, database snapshots, and closed-loop data analysis capabilities into a unified "Omni-Ingestion" architecture.

## Core Value Proposition
- **Enterprise-Ready**: Designed for complex corporate environments with robust resource governance and identity management.
- **Omni-Source Agnostic**: "Everything is a Source File" architecture. Database tables, web pages, and local files are all treated as standard ingestion artifacts.
- **Zero-Flicker UX**: Fragment-based UI architecture ensures seamless interaction without full-page reloads.
- **Data-Driven**: Features a "Build-First" architecture for data analysis, ensuring physical DB readiness before conversation.

## Key Features (v9.5.1)
- **Omni-Ingestion Unification**: A single, unified entry point for File Upload, Directory Scan, Text Paste, Web Crawling, and Database Snapshots.
- **Database Snapshots**: Native support for exporting tables and custom SQL queries from 9+ database types directly into the ingestion pipeline as CSVs.
- **Zero White Screen**: Complete elimination of page flickers during configuration changes and chat interactions using Streamlit Fragments.
- **Decoupled Pure Chat**: Filesystem-agnostic chat mode with direct LLM streaming channels.
- **Codebase Cartography**: Automated system for generating codebase maps, dependency graphs, and dead code reports.
- **Universal Attachment Parsing**: Unified pipeline for chat attachments and KB construction, supporting 20+ formats.
