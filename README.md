# RAG Pro Max - 企业级智能文档问答与数据分析系统

**当前版本**: v8.1.1 (Flagship Dual-Core Edition)  
![Version](https://img.shields.io/badge/version-v8.1.1-purple)

RAG Pro Max v8.1.1 进一步贯彻了“极简融合”的设计理念，通过 **「UI 极简融合 (Minimalist UI Fusion)」** 与 **「意图严选路由 (Iron-Gate Routing)」**，打造了真正一体化的智能中台。

---

## 🚀 v8.1.1 核心特性

### 🎨 UI 极简融合 (Minimalist UI Fusion)
- **模式瘦身**: 移除了独立的“📊 数据分析”导航入口，将数据分析能力内化为系统基础能力。
- **能力全源化**: 无论文件上传、粘贴文本还是网页抓取，均可通过勾选「高级选项」中的“智能数据分析”来激活 SQL 逻辑核。
- **界面净化**: 侧边栏逻辑深度优化，提供更纯净的交互体验。

### 🛡️ 意图严选路由 (Iron-Gate)
- **绝对受控**: 彻底解决自动唤醒 SQL 引擎的隐患。现在，唯有“物理底座就绪”且“用户手动开启开关”时，系统才会启动战略推演工作坊。
- **实时审计**: 后台日志实时追踪路由决策（Route Discovery），确保每一条回答的产生逻辑均可追溯。

### 🧬 双核联动组装 (Dual-Core Integration)
- **全量语义底座**: 无论文件源头为何，100% 经过 RAG 切片，确保博学问答永不掉线。
- **逻辑影子增强**: 针对“真数据”自动生成影子数据库，支持按需激活的 SQL 计算与可视化分析。

### 🛡️ 架构鲁棒性加固 (Robustness)
- **全局单例执行器**: 解决大型 Streamlit 应用中的作用域冲突，保障多核推演 100% 成功。
- **监控大盘自愈**: 彻底根治 Pandas 热加载时的 TypeError，支持强制热重载。

### 🛡️ 旗舰级治理中心 (Flagship Governance)
- **个体安全调节舱**: 引入“单兵作战”管理，支持为特定用户设置专属会话有效期及定点强制熔断。
- **全合规扫描引擎**: 秒级识别物理存储中的损坏索引、容量超限（>500MB）及长期闲置资产。

## 🛠️ 安装与启动

1. **环境准备**: Python 3.10+ / macOS (推荐) 或 Linux
2. **安装依赖**: `pip install -r requirements.txt`
3. **启动系统**: `streamlit run src/apppro.py`
