# 川香小厨美团销售数据测试包

## 📊 数据概览

### 1. 主要销售数据 (meituan_restaurant_sales.csv)
- **订单数量**: 20笔订单
- **时间范围**: 2025-01-15 至 2025-01-17
- **总销售额**: 约680元
- **平均客单价**: 34元
- **热销菜品**: 宫保鸡丁、水煮鱼、麻辣香锅

### 2. 菜品信息 (restaurant_menu.csv)
- **菜品种类**: 12道招牌菜
- **分类**: 川菜、素菜、招牌菜、凉菜、家常菜
- **利润率**: 52%-75%
- **辣度等级**: 不辣到重辣

### 3. 客户信息 (customers.csv)
- **客户数量**: 20位客户
- **会员等级**: 普通、银卡、金卡、钻石
- **地区分布**: 北京各区
- **消费习惯**: 不同偏好分类

## 🧪 测试场景建议

### 基础查询测试
1. "今天的销售额是多少？"
2. "哪道菜最受欢迎？"
3. "客单价最高的订单是哪个？"

### 分析类测试
1. "分析不同菜品类别的销售情况"
2. "哪个时间段订单最多？"
3. "钻石会员的消费习惯如何？"

### 复杂查询测试
1. "利润率最高的菜品销售情况如何？"
2. "重辣菜品的评分和销量关系"
3. "不同支付方式的客户偏好分析"

## 📈 预期分析结果

### 销售趋势
- 晚餐时段(18:00-20:00)订单较多
- 招牌菜和川菜是主力品类
- 微信支付和支付宝使用率相当

### 客户洞察
- 钻石会员消费能力强，偏爱招牌菜
- 普通会员更倾向于选择素菜
- 客户评分整体较高(3-5分)

### 运营建议
- 可以在晚餐时段推出套餐优惠
- 水煮鱼等招牌菜可以作为引流产品
- 素菜类可以针对健康饮食客群推广

## 🚀 使用方法

1. 将三个CSV文件上传到RAG Pro Max系统
2. 创建新的知识库或添加到现有知识库
3. 等待数据处理完成
4. 开始提问测试数据分析功能
