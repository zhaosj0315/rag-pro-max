# 数据分析场景测试说明

本目录包含3种典型的数据分析场景测试文件。

## 📋 场景说明

### 场景1: 有真实数据的 CSV ✅

**文件**: `promotions.csv`

**特点**:
- 包含真实的业务数据（4条促销活动记录）
- 有完整的字段和数据值
- 可以直接导入和查询

**系统行为**:
- 检测到表已有数据
- **不生成虚拟数据**
- 直接使用真实数据进行分析

**测试结果**: ✅ 通过
- 成功导入 4 条数据
- 查询返回正确结果

---

### 场景2: 有字段定义但无数据 ✅

**文件**: `customer_orders_schema.md`

**特点**:
- 定义了完整的表结构
- 包含所有字段的名称、类型、说明
- 但没有实际数据

**系统行为**:
- 检测到表为空
- **自动生成虚拟数据**（基于字段定义）
- 生成 5 条符合字段定义的测试数据
- 执行查询并返回结果

**测试结果**: ✅ 通过
- 自动生成 5 条虚拟数据
- 查询返回 4 条聚合结果（按地区统计）

---

### 场景3: 只有业务描述无字段定义 ✅

**文件**: `sales_performance_desc.md`

**特点**:
- 只有表名和业务描述
- 没有字段定义
- 没有实际数据

**系统行为**:
- 根据业务描述推断表结构
- **自动生成字段定义**
- **自动生成虚拟数据**
- 执行查询并返回结果

**测试结果**: ✅ 通过
- 推断出 8 个合理的字段
- 自动生成 5 条虚拟数据
- 查询返回 5 条结果

1. **有真实数据时**: 直接上传 CSV/Excel 文件
