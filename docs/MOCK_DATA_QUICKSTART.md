# 虚拟数据生成 - 快速开始

## 🚀 5分钟上手

### 场景：你只有表结构，没有数据

**之前的问题**：
```
用户: "请分析各行业销售额最高的企业"
系统: "查询成功，但未找到匹配记录"  ❌
```

**现在的体验**：
```
用户: "请分析各行业销售额最高的企业"
系统: 
  🎲 检测到表为空，正在生成虚拟数据...
  ✅ 成功生成 30 条记录
  📊 查询结果：
     1. 信息技术 - 华为技术有限公司 - 广东 - 312.4亿
     2. 医疗健康 - 恒瑞医药 - 江苏 - 198.7亿
     ...
```

## 📝 使用步骤

### 1. 准备表结构

你可以通过以下任一方式提供表结构：

**方式A：上传 SQL DDL 文件**
```sql
CREATE TABLE sales_data (
    product_id TEXT,
    product_name TEXT,
    category TEXT,
    sales_amount REAL,
    sales_date TEXT
);
```

**方式B：上传 Excel 模板**
- 第一行为列名
- 可以没有数据行

**方式C：定义 JSON Schema**
```json
{
  "tables": {
    "sales_data": {
      "desc": "销售数据表",
      "cols": [
        {"name": "product_id", "comment": "产品ID"},
        {"name": "sales_amount", "comment": "销售额"}
      ]
    }
  }
}
```

### 2. 开始提问

直接在数据分析模式下提问，系统会：
1. 自动检测表是否有数据
2. 如果没有，自动生成虚拟数据
3. 执行查询并返回结果

**就这么简单！** 🎉

## 💡 提示

### 获得更好的数据质量

在字段定义中提供更多信息：

```json
{
  "name": "category",
  "type": "TEXT",
  "comment": "产品类别，可选值: 手机、电脑、家电、家具"
}
```

系统会根据这些信息生成更真实的数据。

### 查看生成过程

在控制台可以看到详细的生成日志：
```
⚠️ [数据检查] 表 'sales_data' 为空，需要生成虚拟数据
🎲 [虚拟数据] 正在为表 'sales_data' 生成测试数据...
✅ [虚拟数据] 表 'sales_data' 成功生成 30 条记录
```

### 禁用自动生成

如果你不想自动生成数据，先导入真实数据：
```python
import pandas as pd
df = pd.read_csv('real_data.csv')
# 系统会使用真实数据，不会生成虚拟数据
```

## ❓ 常见问题

**Q: 生成的数据真实吗？**  
A: 系统使用 LLM 根据表结构和业务背景生成数据，尽可能真实合理。

**Q: 每次都会重新生成吗？**  
A: 不会。数据生成后会保存在数据库中，下次直接使用。

**Q: 可以控制生成的数据量吗？**  
A: 默认生成 20-30 条。可以修改代码中的数量参数。

**Q: 如果 LLM 生成失败怎么办？**  
A: 系统会自动切换到规则引擎，确保一定能生成数据。

**Q: 会影响真实数据吗？**  
A: 不会。系统会先检查表是否有数据，只在空表时才生成。
