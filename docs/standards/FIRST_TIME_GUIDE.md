# 🚀 首次使用指南 (First Time Guide)

## 👋 欢迎体验 RAG Pro Max v6.6.5 (Repair & Enhancement Edition)

本指南将帮助您快速上手，体验全新的**全屏指挥中心 UI**、**饱和式文档搬运**与**智能数据分析师智能体**。

## 🚀 3步极速启动

### 1️⃣ 开启全屏沉浸体验
登录进入系统后，您将看到全新的 **“极光战略指挥中心”**。
- **全宽布局**: 95% 全宽视野，图表与报告展示更震撼。
- **全局状态**: 底部 HUD 实时展示 GPU 加速与计算状态。
- **浮动导航**: 留意右下角胶囊，随时帮您在长会话中快速回顶或下探。

### 2️⃣ 构建饱和知识库
在 **"🔗 网址抓取"** 模块：
- **全量模式**: 输入阿里云或技术文档链接，系统将自动进入“饱和模式”，为您一个不漏地搬运整本产品手册。
- **智能降速**: 系统会自动模拟人类阅读行为，确保抓取过程不被封锁。

### 3️⃣ 玩转数据分析 2.0 (🆕 v6.6.5)
1. 点击顶部导航的 **“📊 数据分析”**。
2. 上传您的 CSV 或 Excel（建议文件名使用英文）。
3. **提问**: “分析环比增长异常的原因”。
4. **惊喜**: 系统不仅会查询数据，还会通过 **“跨阶段记忆”** 自动深入挖掘，并产出中英双语结论。

## 💡 v6.6.5 核心技术亮点

- **🧠 分析自愈**: 自动对齐您的表名，不再反复造假数据。
- **⚡ 按需加载**: 即使库里有几百张表，也能秒级响应。
- **🕷️ 饱和爬虫**: 彻底复刻高性能原生脚本，抓取率 100%。
- **🎨 悬浮导航**: 长对话翻阅再也不费力。
